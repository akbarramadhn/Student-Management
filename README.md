# Student Management

Aplikasi sederhana berbasis ReactJS untuk menampilkan dan mengelola tampilan data mahasiswa dalam bentuk tabel.

## Deskripsi Project

Project ini dibuat untuk memenuhi tugas **React UI Implementation Practice** pada modul Frontend Development. Aplikasi menampilkan data mahasiswa menggunakan data dummy yang disimpan di dalam state React.

## Teknologi yang Digunakan

- ReactJS
- Vite
- JavaScript
- Vanilla CSS

## Fitur Aplikasi

1. Menampilkan data mahasiswa dalam bentuk tabel.
2. Menampilkan jumlah mahasiswa terdaftar.
3. Menampilkan jumlah program studi.
4. Menampilkan jam digital secara real-time.
5. Menyediakan sidebar responsif dengan fitur buka dan tutup.

## Implementasi React Hooks

| Teknologi | Implementasi |
|---|---|
| useState | Menyimpan data mahasiswa dan waktu saat ini |
| useEffect | Menjalankan interval jam digital |
| .map() | Menampilkan data mahasiswa ke dalam tabel |
| setInterval() | Memperbarui waktu setiap satu detik |
| clearInterval() | Membersihkan interval saat komponen dilepas |

## Menjalankan Project

Pastikan Node.js sudah terpasang, kemudian jalankan perintah berikut:

```bash
npm install
npm run dev
```

Buka alamat lokal yang muncul pada terminal untuk melihat aplikasi.
